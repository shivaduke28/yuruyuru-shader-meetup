1. 記法とボリュームレンダリング方程式

媒質（フォグ）の性質を次の量で表す。

  • \(\sigma(x)\): 散乱係数。単位長さあたり、光が散乱される割合
  • \(\alpha(x)\): 吸収係数
  • \(\kappa(x) := \sigma(x) + \alpha(x)\): 消散係数。単位は \(\mathrm{m}^{-1}\)（シーンの座標の 1 単位を 1 m とする）。パラメータ density（高さフォグの \(a\)、3 節）と uniformDensity（距離フォグの \(\kappa_u\)）はこの \(\kappa\) の値である
  • \(\rho(x) := \sigma(x) / \kappa(x)\): 散乱アルベド。\(0 \le \rho \le 1\) で、1 なら吸収なし
  • \(\tau(x, y) := \int_x^y \kappa(p)\,\lVert dp \rVert\): 光学的深さ。\(x\) から \(y\) までの消散係数の線積分
  • \(T(x, y) := \exp(-\tau(x, y))\): 透過率（Beer–Lambert の法則）
  • \(\beta(x, \omega_o, \omega_i)\): 位相関数。\(x\) で \(\omega_i\) から来た光が \(\omega_o\) の向きへ散乱する割合。\(\int_{S^2} \beta\, d\omega_i = 1\)。 この文書では 2 つの向きのなす角 \(\theta\) だけに依存するとして \(\beta(\cos\theta)\) とも書く

カメラ位置 \(c\)（コードの ro）、サーフェスの点 \(p\)、距離 \(d = \lVert p - c \rVert\)（当たらなければ \(d = \infty\)）、 レイの向き \(\mathrm{rd} = (p - c) / d\)（カメラから遠ざかる単位ベクトル。コードの rd）、レイ上の点 \(x_t := c + t\,\mathrm{rd}\)（\(0 \le t \le d\)）とする。

後の節で使う記号とコードの対応: 環境光 \(L_a\) = ambient、アルベド \(\rho\) = albedo、発光 \(E\) = emission、 太陽の色 × 強さ \(I\) = u_lightColor、太陽の向き \(l\) = u_lightDir、高さフォグの \(a, f, h\) = density, falloff, baseHeight、 距離フォグの \(\kappa_u\) = uniformDensity、距離フォグのアルベド \(\rho_u\) = uniformAlbedo。画面に出す色はコードの col。

カメラに届く放射輝度は、ボリュームレンダリング方程式で

\[ \begin{aligned} L(c) = {}& T(c, x_d)\,L_o(x_d) \\ &+ \int_0^d T(c, x_t)\,\bigl(\sigma(x_t)\,L_s(x_t) + L_e(x_t)\bigr)\,dt \end{aligned} \]

と書ける。右辺の第 1 項はサーフェスの色 \(L_o\) が透過して届く分、第 2 項はレイ上の各点でフォグが散乱する光 \(\sigma L_s\) と発光 \(L_e\) が、そこからカメラまでの透過率 \(T(c, x_t)\) で減衰して届く分（内散乱）である。 散乱項 \(L_s\) は、その点に全方向から入ってくる光 \(L_i\) を位相関数で重みづけして足したものである。

\[ L_s(x) := \int_{S^2} \beta(x, -\mathrm{rd}, \omega)\,L_i(x, \omega)\,d\omega . \]

2. 距離フォグ

ボリュームレンダリング方程式を一番簡単な場合で計算する。\(\kappa\) が空間で一定、吸収なし（\(\sigma = \kappa\)、\(\rho = 1\)）、発光なし、 フォグを照らす光は全方向から同じ色の環境光 \(L_a\) で、位相関数は等方（\(\beta = 1/4\pi\)）とする。すると散乱項は \(L_s = \int_{S^2} \frac{1}{4\pi} L_a\, d\omega = L_a\) で位置に依らず、透過率は \(T(c, x_t) = e^{-\kappa t}\) だから

\[ \begin{aligned} L(c) &= e^{-\kappa d} L_o + \int_0^d e^{-\kappa t}\,\kappa\,L_a\,dt \\ &= e^{-\kappa d} L_o + \bigl(1 - e^{-\kappa d}\bigr)\, L_a \end{aligned} \]

となる。コードでは mix(fogColor, color, exp(-density * dist)) である。

vec3 fogColor = ambient;
float T = exp(-density * dist); // 透過率: 距離 dist で残る光の割合
color = mix(fogColor, color, T);

上で置いた仮定のうち、以下の節で 1 つずつ外していくのは次の 3 つである。

  • フォグの消散係数 \(\kappa\) がシーン内で均一（→ 高さフォグで外す）
  • フォグを照らす光が全方向から同じ色で当たる（→ 太陽光で外す）
  • 光が全方向に均一に散乱する（→ 位相関数で外す）

距離フォグのアルベド。距離フォグに対してアルベド \(\rho_u\)（厳密には散乱アルベド）を考えると、内散乱は \(L_a\rho_u\,(1 - e^{-\kappa d})\) になり、環境光と内散乱の色を別にできる。 しかし距離フォグが無限に広がっていることを考えると、環境光や空の色と同じ（\(\rho_u = 1\)）である方が自然、という見方もある。

3. 指数関数高さフォグ

点 \(p = (p_x, p_y, p_z)\) の消散係数を、高さ \(p_y\) の指数関数にする [1]。以下、ベクトルの成分は同じ添字で書く（\(c_y\)、\(\mathrm{rd}_y\)、\(l_y\)）。

\[ \kappa(p) = a\,\exp\bigl(-f\,(p_y - h)\bigr), \qquad a > 0,\ f > 0 \]

\(a\) は高さ \(h\) での消散係数（density）、\(f\) は減衰の速さ（falloff）、\(h\) は減衰が始まる高さ（baseHeight）である。 レイ上の点 \(x_t = c + t\,\mathrm{rd}\) では \((x_t)_y = c_y + t\,\mathrm{rd}_y\) なので、光学的深さは初等的に積分できる。

\[ \begin{aligned} \tau(c, x_d) &= \int_0^d a\, e^{-f(c_y + t\,\mathrm{rd}_y - h)}\,dt \\ &= a\, e^{-f(c_y - h)} \int_0^d e^{-f\,\mathrm{rd}_y t}\,dt \\ &= \frac{a\, e^{-f(c_y - h)}}{f\,\mathrm{rd}_y}\Bigl(1 - e^{-f\,\mathrm{rd}_y d}\Bigr) \end{aligned} \]

\(\mathrm{rd}_y = 0\) でも発散せず、極限は \(a e^{-f(c_y - h)}\,d\) である。 \(d = \infty\) のとき、\(\mathrm{rd}_y > 0\) なら \(\tau(c, x_d) = \frac{a e^{-f(c_y - h)}}{f\,\mathrm{rd}_y}\)、\(\mathrm{rd}_y \le 0\) なら \(\tau(c, x_d) = \infty\) である。

コードでは \(a, f, h\) を vec3 にして、RGB ごとに別の値を持たせている。

// exp の引数を float の範囲内で止める。d = 1e5 のレイや遠い終点で exp が inf になると、density = 0 のとき 0 × inf = NaN になる
vec3 expClamped(vec3 x) {
  return exp(min(x, vec3(80.0)));
}

// 消散係数   kappa(p) = a * exp(-f * (p.y - h))
// 光学的深さ tau = a * exp(-f * (c.y - h)) * (1 - exp(-f * rd.y * d)) / (f * rd.y)
vec3 heightFogOpticalDepth(vec3 c, vec3 rd, float d, vec3 a, vec3 f, vec3 h) {
  vec3 k0 = a * exp(-f * (c.y - h)); // カメラ位置での消散係数
  vec3 fv = f * rd.y;
  bvec3 isFlat = lessThan(abs(fv), vec3(1e-4));
  vec3 fvSafe = mix(fv, vec3(1.0), vec3(isFlat));
  vec3 slanted = k0 * (1.0 - expClamped(-fvSafe * d)) / fvSafe;
  vec3 horizontal = k0 * d;
  return mix(slanted, horizontal, vec3(isFlat));
}

vec3 fogTransmittance(vec3 c, vec3 rd, float d) {
  vec3 tau = heightFogOpticalDepth(c, rd, d, u_density, u_falloff, u_baseHeight)
           + u_uniformDensity * d;
  return exp(-tau);
}

4. アルベドと発光

アルベド \(\rho\) を定数、発光を \(\kappa\) に比例する \(L_e(x) = E\,\kappa(x)\)（\(E\) は定数）、環境光を定数 \(L_a\) とする （\(L_e\) を定数にすると \(\int_0^d T(c, x_t)\,dt\) が指数積分になって初等関数で閉じないので、\(\kappa\) に比例させる）。 高さフォグでも \(L_s(x) = L_a\) はレイ上で一定なので、被積分関数は \(T(c, x_t)\,\kappa(x_t)\,(L_a\rho + E)\) になる。 \(\frac{d}{dt}T(c, x_t) = -\kappa(x_t)\,T(c, x_t)\) を使うと、内散乱は

\[ \begin{aligned} \int_0^d T(c, x_t)\,\bigl(\sigma(x_t)\,L_a + L_e(x_t)\bigr)\,dt &= (L_a\rho + E) \int_0^d T(c, x_t)\,\kappa(x_t)\,dt \\ &= -(L_a\rho + E) \int_0^d \frac{d}{dt}T(c, x_t)\,dt \\ &= (L_a\rho + E)\,\bigl(1 - T(c, x_d)\bigr) \end{aligned} \]

になる。\(1 - T(c, x_d)\) に掛かる \(L_a\rho + E\) が、コードで fogColor = ambient * albedo + emission と書いているものである。

5. 太陽光

太陽は向き \(l\)（光源へ向かう単位ベクトル、\(l_y > 0\)）の平行光源とし、色と強さを \(I\)（反射率 1 の Lambert 面が輝度 \(I\) で見える強さ。コードの u_lightColor）とする。 太陽光が高さフォグに関わる経路は、サーフェスに届く太陽光の減衰、カメラへの内散乱、サーフェスへの内散乱の 3 つで、以下順に書く。エネルギー保存を保つなら 3 つとも入れる。

5.1 太陽の減衰（sun attenuation）

点 \(p\) から向き \(\omega\) に無限遠までの透過率を \(T_\infty(p, \omega) := \exp\bigl(-\int_0^\infty \kappa(p + t\omega)\,dt\bigr)\) と書く。 サーフェスの点 \(p\) に届く太陽光は、フォグがないときの \(T_\infty(p, l)\) 倍になる。3 節の式で \(c = p\)、\(\mathrm{rd} = l\)、\(d = \infty\) とすれば

\[ \begin{aligned} \tau_\infty(p, l) &= \frac{a\, e^{-f(p_y - h)}}{f\, l_y} = \frac{\tau_\uparrow(p)}{l_y} \\ \tau_\uparrow(p) &:= \frac{\kappa(p)}{f} \\ T_\infty(p, l) &= e^{-\tau_\infty(p, l)} \end{aligned} \]

である。\(\tau_\uparrow(p)\) は高さ \(p_y\) から真上に無限遠までの光学的深さで、コードの tauFromTop である。 

// 真上に無限遠までの高さフォグの光学的深さ tau(y) = kappa(y) / f
vec3 tauFromTop(float y) {
  return u_density * expClamped(-u_falloff * (y - u_baseHeight)) / u_falloff;
}

vec3 sunTransmittance(vec3 p) {
  if (!u_sunAttenuation) return vec3(1.0);
  return exp(-tauFromTop(p.y) / u_lightDir.y);
}

5.2 カメラへの内散乱（sun inscatter）

太陽光による散乱項は

\[ L_s(x) = \pi\,\beta(\cos\theta)\,I\,T_\infty(x, l), \qquad \cos\theta := \mathrm{rd} \cdot l \]

である。\(\pi\beta(\cos\theta)\) はレイ上で定数なので積分の外に出る（コードの sunPhase。7 節。等方なら \(1/4\)）。 ボリュームレンダリング方程式の散乱項に入れると、太陽光の内散乱は

\[ \pi\beta(\cos\theta)\, I\, \rho \int_0^d T(c, x_t)\,\kappa(x_t)\,T_\infty(x_t, l)\,dt \]

である。\(\tau_\uparrow(x_t) = \tau_\uparrow(c)\,e^{-f\,\mathrm{rd}_y t}\) なので、\(\xi = \tau_\uparrow(x_t)\) と変数変換すると \(\kappa(x_t)\,dt = -\,d\xi / \mathrm{rd}_y\)、\(T(c, x_t) = e^{-(\tau_\uparrow(c) - \xi)/\mathrm{rd}_y}\)、\(T_\infty(x_t, l) = e^{-\xi/l_y}\) で、

\[ \begin{aligned} &\int_0^d T(c, x_t)\,\kappa(x_t)\,T_\infty(x_t, l)\,dt \\ &= \frac{e^{-\tau_\uparrow(c)/\mathrm{rd}_y}}{\mathrm{rd}_y} \int_{\tau_\uparrow(x_d)}^{\tau_\uparrow(c)} e^{\xi\,(1/\mathrm{rd}_y - 1/l_y)}\,d\xi \\ &= \frac{T_\infty(c, l) - T(c, x_d)\,T_\infty(x_d, l)}{1 - \mathrm{rd}_y / l_y} \end{aligned} \]

となる。コードの sunInscatter がこれである。 

vec3 sunInscatter(vec3 c, vec3 rd, float d) {
  vec3 tauView = heightFogOpticalDepth(c, rd, d, u_density, u_falloff, u_baseHeight);
  vec3 Tview = exp(-tauView);
  vec3 scatter;
  if (!u_sunAttenuation) {
    scatter = 1.0 - Tview;
  } else {
    vec3 TsunCam = sunTransmittance(c);
    vec3 TsunEnd = sunTransmittance(c + rd * d);
    float den = 1.0 - rd.y / u_lightDir.y;
    scatter = abs(den) < 1e-2 ? TsunCam * tauView : (TsunCam - Tview * TsunEnd) / den;
  }
  vec3 hf, uf;
  fogMixFactors(c, rd, d, hf, uf);
  return u_lightColor * sunPhase(dot(rd, u_lightDir)) * u_albedo * scatter * hf;
}

5.3 サーフェスへの内散乱（sun inscatter ambient）

太陽光がフォグで散乱してサーフェスに届く分は、正しくはサーフェスの点 \(p\) から見た半球の全方向について 5.2 の積分を取り、法線との余弦で重みづけて足す。 これは閉じないので、空へ向かう代表方向 1 本 \(\hat\omega\)（6 節。コードの SKY_DIR）で \(d = \infty\) の内散乱を評価し、環境光に足す。 位相関数も \(\hat\omega\) をレイの向きにして \(\cos\theta = \hat\omega \cdot l\) で評価する。代表方向 1 本がここの近似で、7 節の \(g\) が大きいほど誤差も大きい。 

vec3 sunInscatterAmbient(vec3 p) {
  return sunInscatter(p, SKY_DIR, 1e5);
}

6. サーフェスに届く環境光

サーフェスの点 \(p\)（法線 \(n\)）に向き \(\omega\) から届く環境光は、空の光 \(L_a\) がフォグを通り抜ける分と、途中のフォグが散乱して届く分の和で、 \(L_a\,T_\infty(p, \omega) + \rho\,L_a\,\bigl(1 - T_\infty(p, \omega)\bigr)\) である（4 節と同じ計算）。これを \(n\) の側の半球 \(\Omega\) で余弦重みつきで平均すると

\[ \begin{aligned} &L_a\,\Phi(p) + \rho\,L_a\,\bigl(1 - \Phi(p)\bigr), \\ \Phi(p) &:= \frac{1}{\pi}\int_{\Omega} T_\infty(p, \omega)\,(n \cdot \omega)\,d\omega \end{aligned} \]

になる。\(\Phi(p)\) は半球平均透過率である。\(\rho = 1\) なら \(L_a\) に戻る。実装ではこの 2 項を sky attenuation と sky inscatter ambient の 2 つに分けて切り替えられる。

\(\Phi(p)\) の積分は初等関数で書けないので、天頂角の余弦が \(2/3\) の向き \(\hat\omega\) 1 本の値 \(T_\infty(p, \hat\omega) = e^{-1.5\,\tau_\uparrow(p)}\) で置き換える。上向きのサーフェス（\(n = (0, 1, 0)\)）では、\(\tau_\uparrow(p)\) がどの値でも \(\lvert \Phi(p) - T_\infty(p, \hat\omega) \rvert \le 0.04\) である。 サーフェスの向きによらず同じ \(\hat\omega\) を使う。側面では \(\Omega\) の下半分が地面までのフォグを通るので、正しくは \(\Phi(p)\) はこれより小さいが、 地面の高さをシェーダーに持ち込まないために、この 1 本で済ませている。 

const vec3 SKY_DIR = vec3(0.0, 2.0 / 3.0, 0.745356); // 長さ 1、y = 2/3
vec3 skyTransmittance(vec3 p) {
  return exp(-tauFromTop(p.y) / SKY_DIR.y);
}

vec3 shade(vec3 p, vec3 n) {
  float diff = max(dot(n, u_lightDir), 0.0);
  float sh = shadow(p + n * 0.02, u_lightDir);
  vec3 sun = u_lightColor * sunTransmittance(p);
  vec3 ambient = u_ambient;
  if (u_skyAttenuation || u_skyInscatterAmbient || u_emissionAmbient) {
    vec3 T = skyTransmittance(p);
    if (u_skyAttenuation) ambient = u_ambient * T;
    if (u_skyInscatterAmbient) ambient += u_ambient * u_albedo * (1.0 - T);
    if (u_emissionAmbient) ambient += u_emission * (1.0 - T);
  }
  if (u_sunInscatterAmbient) ambient += sunInscatterAmbient(p);
  return surfaceAlbedo(p) * (diff * sh * sun + ambient);
}

surfaceAlbedo はサーフェスの反射率、shadow は太陽へのレイマーチによるハードシャドウ（0 か 1）である。 発光するフォグに囲まれたサーフェスには全方向から発光が届くので、emission ambient では同じ代表方向の \(E(1 - T)\) を足す。

7. 位相関数

散乱する向きの偏りは Henyey–Greenstein の位相関数で表す。

\[ \beta_{HG}(\cos\theta) = \frac{1}{4\pi}\,\frac{1 - g^2}{\bigl(1 + g^2 - 2g\cos\theta\bigr)^{3/2}}, \quad \cos\theta = \mathrm{rd} \cdot l \]

\(g = 0\) で等方、\(g > 0\) で前方散乱（光の進む向きに散乱しやすい）、\(g < 0\) で後方散乱。 \(\cos\theta = 1\) は太陽を見るレイ（\(\mathrm{rd} = l\)）で、前方散乱ではここが最大になる。だから \(g > 0\) で太陽の周りのフォグが明るくなり、反対側が暗くなる。

5 節の通り、平行光源では \(\pi\beta(\cos\theta)\) がレイ上で定数なので、位相関数を入れても閉じた式はそのまま使える。 係数として 5.2、5.3、8 節の 3 つに同じ値をかける。環境光は全方向から同じ色なので \(\int \beta\, d\omega = 1\) となり、位相関数の形は関係しない。 

// 位相関数 × π。g = 0 なら 1/(4π) × π = 1/4 (等方)
float sunPhase(float cosTheta) {
  float g = u_phaseG;
  float g2 = g * g;
  return 0.25 * (1.0 - g2) / pow(max(1.0 + g2 - 2.0 * g * cosTheta, 1e-4), 1.5);
}

8. 光芒: 影つきの数値積分

遮蔽物が太陽光を遮ると、フォグの中に影の境界が光芒として見える。5.2 の被積分関数に、点 \(x_t\) から太陽が見えるかの可視性 \(V(x_t) \in \{0, 1\}\) を掛けたもの

\[ \pi\beta(\cos\theta)\, I\, \rho \int_0^d T(c, x_t)\,\kappa(x_t)\,T_\infty(x_t, l)\,V(x_t)\,dt \]

は閉じた式では書けないので、ここだけ数値積分する。レイを等間隔のステップでレイマーチし、各サンプル点から太陽へ影のレイを飛ばして \(V(x_t)\) を求める。 影のレイはシーンの SDF に対する sphere tracing である（fogShadow）。

等間隔のサンプルは影の境界に縞を作るので、縞が出ないようにサンプルの開始位置をピクセルごと、フレームごとにジッターする。 誤差の大きさはステップの長さで決まり、ステップ数を 2 倍にすれば半分弱になる。

この実装では 32 ステップで 48 m まで歩き、その先は影を無視して 5.2 の閉じた式に切り替え、手前の透過率をかけて足す。 レイの透過率 \(T(c, x_t)\) が 0.005 を切ったら打ち切る。 

const int SHADOW_STEPS = 32;
const float SHADOW_RANGE = 48.0;
vec3 sunInscatterShadowed(vec3 c, vec3 rd, float d, vec2 pix, vec3 R) {
  float tEnd = min(d, SHADOW_RANGE);
  float dt = tEnd / float(SHADOW_STEPS);
  float jitter = fract(hash21(pix) + 0.618034 * u_frame);
  vec3 sum = vec3(0.0);
  for (int i = 0; i < SHADOW_STEPS; i++) {
    float t = (float(i) + jitter) * dt;
    vec3 p = c + rd * t;
    vec3 Tview = pow(fogTransmittance(c, rd, t), R);
    if (max(Tview.r, max(Tview.g, Tview.b)) < 0.005) break;
    float vis = fogShadow(p);
    if (vis <= 0.0) continue;
    vec3 kappaH = R * u_density * exp(-u_falloff * (p.y - u_baseHeight));
    sum += Tview * u_albedo * kappaH * sunTransmittance(p) * (vis * dt);
  }
  vec3 result = u_lightColor * sunPhase(dot(rd, u_lightDir)) * sum;
  if (d > tEnd) {
    vec3 pEnd = c + rd * tEnd;
    result += pow(fogTransmittance(c, rd, tEnd), R) * sunInscatter(pEnd, rd, d - tEnd);
  }
  return result;
}

サーフェスへの内散乱（5.3）は影を見ない。\(R\) は 9 節の \(\bar R(c, x_d)\) で、ノイズなしなら 1 である。

9. ノイズ

フォグにムラをつけるために、消散係数にノイズ \(r : \mathbb{R}^3 \to [r_{\min}, r_{\max}]\) をかけて \(\tilde\kappa(p) := r(p)\,\kappa(p)\) とする。 光学的深さと透過率は

\[ \begin{aligned} \tilde\tau(c, x_d) &:= \int_0^d r(x_t)\,\kappa(x_t)\,dt = \bar R(c, x_d)\,\tau(c, x_d), \qquad \bar R(c, x_d) := \frac{\int_0^d r(x_t)\,\kappa(x_t)\,dt}{\int_0^d \kappa(x_t)\,dt} \\ \tilde T(c, x_d) &:= e^{-\tilde\tau(c, x_d)} = T(c, x_d)^{\bar R(c, x_d)} \end{aligned} \]

になる。\(\tau(c, x_d)\) は 3 節の閉じた式のままで、\(\bar R(c, x_d)\) だけをサンプルで見積もる。

\(\bar R(c, x_d)\) は、分子と分母をサンプル点 \(x_{t_k}\) での数値積分で置き換えて見積もる。 \(t_0 = 1\)、\(t_k = 1 + 1.4^k\)（\(k \ge 1\)）の 10 点（約 22 m まで）をカメラの近くに固め、各点の重みを \(\kappa(x_{t_k})\,\Delta t_k\)、 \(\Delta t_k := \min(t_k, d) - t_{k-1}\)（\(t_{-1} := 0\)。\(d\) を超えた最初の点で止める。\(d\) が約 22 m より遠ければそこまでの平均）とすると

\[ \bar R(c, x_d) \approx \frac{\sum_k \kappa(x_{t_k})\,\Delta t_k\,r(x_{t_k})}{\sum_k \kappa(x_{t_k})\,\Delta t_k} \]

である。等間隔 \(t_k = dk/N\) にするとサンプル位置がサーフェスまでの距離で決まり、模様がサーフェスと一緒に動いて見える。 

const int NOISE_SAMPLES = 10;
const float NOISE_STEP_EXP = 1.4;
vec3 noiseMean(vec3 c, vec3 rd, float d) {
  vec3 sum = vec3(0.0);
  vec3 wsum = vec3(0.0);
  float t = 1.0;
  float tPrev = 0.0;
  float step = NOISE_STEP_EXP;
  for (int k = 0; k < NOISE_SAMPLES; k++) {
    vec3 p = c + rd * t;
    vec3 kappa = u_density * exp(-u_falloff * (p.y - u_baseHeight)) + u_uniformDensity + vec3(1e-6);
    vec3 w = kappa * (min(t, d) - tPrev); // 区間 [tPrev, t] のうち d までの幅
    sum += w * fogNoise(p);
    wsum += w;
    if (t > d) break;
    tPrev = t;
    t = 1.0 + step;
    step *= NOISE_STEP_EXP;
  }
  return sum / wsum;
}

// main
vec3 T = fogTransmittance(ro, rd, d);
vec3 R = u_noise ? noiseMean(ro, rd, d) : vec3(1.0);
T = pow(T, R);

10. 高さフォグと距離フォグを両方使う

高さフォグと距離フォグを両方入れると、消散係数は \(\kappa = \kappa_h + \kappa_u\)（\(\kappa_h\) は高さフォグ、\(\kappa_u\) は距離フォグ）で、 高さフォグだけの光学的深さを \(\tau_h(t) := \int_0^t \kappa_h(x_s)\,ds\) と書けば、透過率は \(T(c, x_t) = e^{-\tau_h(t) - \kappa_u t}\) と光学的深さを足すだけでよい。しかし \(1 - T\) に掛かる係数は 2 つのフォグで違う。高さフォグは \(L_a\rho + E\)、距離フォグは \(L_a\rho_u\) なので、内散乱は

\[ \begin{aligned} &\int_0^d T(c, x_t)\,\bigl[(L_a\rho + E)\,\kappa_h(x_t) + L_a\rho_u\,\kappa_u\bigr]\,dt \\ &= (L_a\rho + E)\underbrace{\int_0^d T(c, x_t)\,\kappa_h(x_t)\,dt}_{I_h} + L_a\rho_u\underbrace{\int_0^d T(c, x_t)\,\kappa_u\,dt}_{I_u} \end{aligned} \]

になる。係数が同じ（\(L_a\rho + E = L_a\rho_u =: C\)）なら \(\frac{d}{dt}T(c, x_t) = -\bigl(\kappa_h(x_t) + \kappa_u\bigr)\,T(c, x_t)\) から

\[ C\int_0^d T(c, x_t)\,\bigl(\kappa_h(x_t) + \kappa_u\bigr)\,dt = C\,\bigl(1 - T(c, x_d)\bigr) \]

と閉じるが、係数が違うと \(I_h\) と \(I_u\) が別々に要る。\(\kappa_h(x_t)\,T(c, x_t)\) 単独は \(t\) の関数の微分の形にならず、 \(I_h = \int_0^d e^{-\tau_h(t) - \kappa_u t}\,\kappa_h(x_t)\,dt\) は初等的に解けないので、次の近似値を使う。

\[ I_h \approx A := \frac{1 - e^{-\tau_h(d)}}{1 + \kappa_u\,t_h}, \quad I_u \approx B := \frac{1 - e^{-\kappa_u d}}{1 + \tau_h(t_u)} \]

\(t_h\) と \(t_u\) は、それぞれのフォグが散乱する距離の代表値で

\[ \begin{aligned} \tau_h(t_h) &= 1 \\ t_u &:= \frac{\int_0^d t\,\kappa_u e^{-\kappa_u t}\,dt}{\int_0^d \kappa_u e^{-\kappa_u t}\,dt} = \frac{1}{\kappa_u} - \frac{d\,e^{-\kappa_u d}}{1 - e^{-\kappa_u d}} \end{aligned} \]

とする（\(\tau_h(d) \lt 1\) で \(t_h\) がないレイでは \(1/(f\,\mathrm{rd}_y)\) に連続につなぐ）。 分母を \(e^{-\kappa_u t_h}\) ではなく \(1/(1 + \kappa_u t_h)\) にしたのは、水平なレイで \(d = \infty\) のとき \(I_h = \kappa_h / (\kappa_h + \kappa_u)\) に一致するからである。 コードでは fogMixFactors が分母の逆数 hf、uf を、fogScatterWeights が \(A\)、\(B\)（wa、wb）を返す。 \(A\)、\(B\) と数値積分した \(I_h\)、\(I_u\) の差は、既定のパラメータに距離フォグ 0.005〜0.08 を加えた範囲で最大 0.06 である。 片方のフォグしかなければ分母が 1 になり \(A = I_h\)、\(B = I_u\) で厳密である。内散乱は

\[ \bigl(1 - T(c, x_d)\bigr)\,\frac{(L_a\rho + E)\,A + L_a\rho_u\,B}{A + B} \]

とする（fogScatterWeights、mixByScatter）。\(A + B\) で割るのは、\(I_h + I_u = 1 - T(c, x_d)\) は厳密だが \(A + B\) はそうではないので、 近似を 2 つの係数の重みだけに入れて合計は厳密な \(1 - T(c, x_d)\) に合わせるためである。 コードの mixByScatter(h, u, wa, wb) は \((h\,A + u\,B) / (A + B)\) を返す。 

vec3 T = fogTransmittance(ro, rd, d);
vec3 wa, wb;
fogScatterWeights(ro, rd, d, wa, wb);
vec3 inscatter = u_ambient * mixByScatter(u_albedo, u_uniformAlbedo, wa, wb) * (1.0 - T);
col = col * T + inscatter + mixByScatter(u_emission, vec3(0.0), wa, wb) * (1.0 - T);

太陽光と距離フォグ。太陽の減衰（5.1）とサーフェスに届く環境光（6 節）では距離フォグを考えない。 太陽光のカメラへの内散乱（5.2）は、\(T(c, x_t)\) に \(e^{-\kappa_u t}\) が掛かると閉じないので、\(A\) と同じ係数 \(1/(1 + \kappa_u t_h)\)（hf）を掛ける。 距離フォグ自身の太陽光の散乱は考えない。

11. 近似の一覧

どこが厳密でどこが近似かをまとめる。「モデルの下で厳密」とは、単散乱・平行光源・一様な環境光というモデルを認めた上で積分に近似がないことを指す。
