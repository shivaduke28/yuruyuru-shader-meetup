1. 記法とボリュームレンダリング方程式

媒質（フォグ）の性質を次の量で表す。

  • \(\sigma(x)\): 散乱係数。単位長さあたり、光が散乱される割合
  • \(\alpha(x)\): 吸収係数
  • \(\kappa(x) := \sigma(x) + \alpha(x)\): 消散係数。単位は \(\mathrm{m}^{-1}\)。パラメータ density（高さフォグの \(a\)、3 節）と uniformDensity（距離フォグの \(\kappa_u\)）はこの \(\kappa\) の値である。スライドでは「濃さ」と言っている
  • \(\rho(x) := \sigma(x) / \kappa(x)\): 散乱アルベド。\(0 \le \rho \le 1\) で、1 なら吸収なし
  • \(\tau(x, y) := \int_x^y \kappa(p)\,\lVert dp \rVert\): 光学的深さ。\(x\) から \(y\) までの消散係数の線積分
  • \(T(x, y) := \exp(-\tau(x, y))\): 透過率（Beer–Lambert の法則）
  • \(\beta(x, \omega_o, \omega_i)\): 位相関数。\(x\) で \(\omega_i\) から来た光が \(\omega_o\) の向きへ散乱する割合。\(\int_{S^2} \beta\, d\omega_i = 1\)。 この文書では 2 つの向きのなす角 \(\theta\) だけに依存するとして \(\beta(\cos\theta)\) とも書く

シーンは \(y = 0\) の床と、\(xz\) 平面に 8 単位間隔で並ぶ高さ 12 の柱である。 カメラ位置 \(c\)（コードの ro）、サーフェスの点 \(p\)、距離 \(d = \lVert p - c \rVert\)（当たらなければ \(d = \infty\)）、 レイの向き \(\mathrm{rd} = (p - c) / d\)（カメラから遠ざかる単位ベクトル。コードの rd）、レイ上の点 \(x_t := c + t\,\mathrm{rd}\)（\(0 \le t \le d\)）とする。

後の節で使う記号とコードの対応: 環境光 \(L_a\) = ambient、アルベド \(\rho\) = albedo、発光 \(E\) = emission、 太陽の色 × 強さ \(I\) = u_lightColor、太陽の向き \(l\) = u_lightDir、高さフォグの \(a, f, h\) = density, falloff, baseHeight、 距離フォグの \(\kappa_u\) = uniformDensity。画面に出す色はコードの col。

カメラに届く放射輝度は、ボリュームレンダリング方程式で

\[ \begin{aligned} L(c) = {}& T(c, x_d)\,L_o(x_d) \\ &+ \int_0^d T(c, x_t)\,\bigl(\sigma(x_t)\,L_s(x_t) + L_e(x_t)\bigr)\,dt \end{aligned} \]

と書ける。右辺の第 1 項はサーフェスの色 \(L_o\) が透過して届く分、第 2 項はレイ上の各点でフォグが散乱する光 \(\sigma L_s\) と発光 \(L_e\) が、そこからカメラまでの透過率 \(T(c, x_t)\) で減衰して届く分（内散乱）である。 散乱項 \(L_s\) は、その点に全方向から入ってくる光 \(L_i\) を位相関数で重みづけして足したもの

\[ L_s(x) := \int_{S^2} \beta(x, -\mathrm{rd}, \omega)\,L_i(x, \omega)\,d\omega . \]

この文書で扱うのは、フォグで 1 回だけ散乱した光（単散乱）である。2 回以上散乱した光（多重散乱）は入れない。

2. 距離フォグ

ボリュームレンダリング方程式を一番簡単な場合で計算する。\(\kappa\) が空間で一定、吸収なし（\(\sigma = \kappa\)、\(\rho = 1\)）、発光なし、 フォグを照らす光は全方向から同じ色の環境光 \(L_a\) で、位相関数は等方（\(\beta = 1/4\pi\)）とする。すると散乱項は \(L_s = \int_{S^2} \frac{1}{4\pi} L_a\, d\omega = L_a\) で位置に依らず、透過率は \(T(c, x_t) = e^{-\kappa t}\) だから

\[ \begin{aligned} L(c) &= e^{-\kappa d} L_o + \int_0^d e^{-\kappa t}\,\kappa\,L_a\,dt \\ &= e^{-\kappa d} L_o + \bigl(1 - e^{-\kappa d}\bigr)\, L_a \end{aligned} \]

となる。コードでは mix(fogColor, color, exp(-density * dist)) である。

vec3 fogColor = ambient;
float T = exp(-density * dist); // 透過率: 距離 dist で残る光の割合
color = mix(fogColor, color, T);

上で置いた仮定のうち、スライドで 1 つずつ外していくのは次の 3 つである。

  • フォグの消散係数 \(\kappa\) がシーン内で均一（→ 高さフォグで外す）
  • フォグを照らす光が全方向から同じ色で当たる（→ 太陽光で外す）
  • 光が全方向に均一に散乱する（→ 位相関数で外す）

距離フォグにアルベドと発光がない理由。 このリポジトリでは空を単色にして、その色をサーフェスの環境光 \(L_a\) としても使っている。 距離フォグはシーン全体に無限に広がるので、サーフェスに届く環境光はフォグの色と一致しているのが自然であると判断した。

3. 指数関数高さフォグ

点 \(p = (p_x, p_y, p_z)\) の消散係数を、高さ \(p_y\) の指数関数にする [1]。以下、ベクトルの成分は同じ添字で書く（\(c_y\)、\(\mathrm{rd}_y\)、\(l_y\)）。

\[ \kappa(p) = a\,\exp\bigl(-f\,(p_y - h)\bigr), \qquad a > 0,\ f > 0 \]

\(a\) は基準の高さ \(h\) での消散係数（density）、\(f\) は上に行くほど薄くなる速さ（falloff）である。 レイ上の点 \(x_t = c + t\,\mathrm{rd}\) では \((x_t)_y = c_y + t\,\mathrm{rd}_y\) なので、光学的深さは初等的に積分できる。

\[ \begin{aligned} \tau(c, x_d) &= \int_0^d a\, e^{-f(c_y + t\,\mathrm{rd}_y - h)}\,dt \\ &= a\, e^{-f(c_y - h)} \int_0^d e^{-f\,\mathrm{rd}_y t}\,dt \\ &= \frac{a\, e^{-f(c_y - h)}}{f\,\mathrm{rd}_y}\Bigl(1 - e^{-f\,\mathrm{rd}_y d}\Bigr) \end{aligned} \]

\(\mathrm{rd}_y \to 0\)（水平なレイ）では \(a e^{-f(c_y - h)} d\) が極限で、距離フォグと同じ形になる。 \(\mathrm{rd}_y < 0\)（見下ろすレイ）で \(d = \infty\) なら \(\tau = \infty\)、つまり床がなければ地平線より下は \(T = 0\) でフォグの色になる。 \(\mathrm{rd}_y > 0\)（見上げるレイ）なら \(d = \infty\) でも \(\tau = \frac{a e^{-f(c_y - h)}}{f\,\mathrm{rd}_y}\) で有限にとどまる。 

// 消散係数   kappa(p) = a * exp(-f * (p.y - h))
// 光学的深さ tau = a * exp(-f * (c.y - h)) * (1 - exp(-f * rd.y * d)) / (f * rd.y)
vec3 heightFogOpticalDepth(vec3 c, vec3 rd, float d, vec3 a, vec3 f, vec3 h) {
  vec3 k0 = a * exp(-f * (c.y - h)); // カメラ位置での消散係数
  vec3 fv = f * rd.y;
  bvec3 isFlat = lessThan(abs(fv), vec3(1e-4));
  vec3 fvSafe = mix(fv, vec3(1.0), vec3(isFlat));
  vec3 slanted = k0 * (1.0 - exp(-fvSafe * d)) / fvSafe;
  vec3 horizontal = k0 * d;
  return mix(slanted, horizontal, vec3(isFlat));
}

vec3 fogTransmittance(vec3 c, vec3 rd, float d) {
  vec3 tau = heightFogOpticalDepth(c, rd, d, u_density, u_falloff, u_baseHeight)
           + u_uniformDensity * d;
  return exp(-min(tau, vec3(60.0)));
}

\(a, f, h\) はすべて vec3 で、RGB ごとに別の値を持てる。光学的深さが線形なので、高さフォグと距離フォグ（uniformDensity）の 光学的深さは単に足せばよい。\(\exp\) の引数は 60 で止めている（\(\tau = \infty\) になるレイで後の計算に inf が混ざらないようにする。\(e^{-60}\) は 0 と区別がつかない）。

4. フォグの色: アルベドと発光

アルベド \(\rho\) を定数と仮定する。高さフォグでも \(L_s = L_a\) はレイ上で一定である。\(T(c, x_t) = \exp\bigl(-\int_0^t \kappa(x_s)\,ds\bigr)\) を \(t\) で微分すると \(\frac{d}{dt}T(c, x_t) = -\kappa(x_t)\,T(c, x_t)\) なので、内散乱は

\[ \begin{aligned} \int_0^d T(c, x_t)\,\sigma(x_t)\,L_a\,dt &= \rho\,L_a \int_0^d T(c, x_t)\,\kappa(x_t)\,dt \\ &= -\rho\,L_a \int_0^d \frac{d}{dt}T(c, x_t)\,dt \\ &= \rho\,L_a\,\bigl(1 - T(c, x_d)\bigr) \end{aligned} \]

になる。発光 \(L_e\) も \(\kappa\) に比例すると仮定して \(L_e(x) = E\,\kappa(x)\) と書く（\(E\) は定数。\(L_e\) を定数にすると \(\int_0^d T\,dt\) が指数積分になって初等関数で閉じない）。発光項は同じ変形で

\[ \begin{aligned} \int_0^d T(c, x_t)\,L_e(x_t)\,dt &= E \int_0^d T(c, x_t)\,\kappa(x_t)\,dt \\ &= E\,\bigl(1 - T(c, x_d)\bigr) \end{aligned} \]

になり、散乱と足し合わせると

\[ \bigl(1 - T(c, x_d)\bigr)\,(L_a\,\rho + E) \]

である。\(L_a\rho + E\) がフォグの色で、スライドのコードでは fogColor = ambient * albedo + emission と書いている。

高さフォグと距離フォグが混ざるとき。Playground で両方を入れると、消散係数は \(\kappa = \kappa_h + \kappa_u\)（\(\kappa_h\) は高さフォグ、\(\kappa_u\) は距離フォグ）で、 高さフォグだけの光学的深さを \(\tau_h(t) := \int_0^t \kappa_h(x_s)\,ds\) と書けば、透過率は \(T(c, x_t) = e^{-\tau_h(t) - \kappa_u t}\) と光学的深さを足すだけでよい。しかし色が違う。高さフォグの色は \(L_a\rho + E\)、距離フォグの色は \(L_a\) なので、内散乱は

\[ \begin{aligned} &\int_0^d T(c, x_t)\,\bigl[(L_a\rho + E)\,\kappa_h(x_t) + L_a\,\kappa_u\bigr]\,dt \\ &= (L_a\rho + E)\underbrace{\int_0^d T\,\kappa_h\,dt}_{I_h} + L_a\underbrace{\int_0^d T\,\kappa_u\,dt}_{I_u} \end{aligned} \]

になる。\(I_h = \int_0^d e^{-\tau_h(t) - \kappa_u t}\,\kappa_h(t)\,dt\) は初等的に解けないので、次の近似値を使う。

\[ I_h \approx A := \frac{1 - e^{-\tau_h(d)}}{1 + \kappa_u\,t_h}, \quad I_u \approx B := \frac{1 - e^{-\kappa_u d}}{1 + \tau_h(t_u)} \]

\(t_h\) と \(t_u\) は、それぞれのフォグが散乱する距離の代表値で

\[ \begin{aligned} \tau_h(t_h) &= 1 \\ t_u &:= \frac{\int_0^d t\,\kappa_u e^{-\kappa_u t}\,dt}{\int_0^d \kappa_u e^{-\kappa_u t}\,dt} = \frac{1}{\kappa_u} - \frac{d\,e^{-\kappa_u d}}{1 - e^{-\kappa_u d}} \end{aligned} \]

とする（\(\tau_h(d) \lt 1\) で \(t_h\) がないレイでは \(1/(f\,\mathrm{rd}_y)\) に連続につなぐ）。 分母を \(e^{-\kappa_u t_h}\) ではなく \(1/(1 + \kappa_u t_h)\) にしたのは、水平なレイで \(d = \infty\) のとき \(I_h = \kappa_h / (\kappa_h + \kappa_u)\) に一致するからである。 コードでは fogMixFactors が分母の逆数 hf、uf を、fogScatterWeights が \(A\)、\(B\)（wa、wb）を返す。 数値積分した \(I_h\)、\(I_u\) との差は、既定のパラメータに距離フォグ 0.005〜0.08 を加えた範囲で最大 0.06。片方のフォグしかなければ厳密。内散乱は

\[ \bigl(1 - T(c, x_d)\bigr)\,\frac{(L_a\rho + E)\,A + L_a\,B}{A + B} \]

とする（fogScatterWeights、mixByScatter）。\(A + B\) で割るのは、\(I_h + I_u = 1 - T\) は厳密だが \(A + B\) はそうではないので、 近似を色の混ぜ方だけに入れて合計は厳密な \(1 - T\) に合わせるためである。 コードの mixByScatter(h, u, wa, wb) は \((h\,A + u\,B) / (A + B)\) を返す。 

vec3 T = fogTransmittance(ro, rd, d);
vec3 wa, wb;
fogScatterWeights(ro, rd, d, wa, wb);
vec3 inscatter = u_ambient * mixByScatter(u_albedo, vec3(1.0), wa, wb) * (1.0 - T);
col = col * T + inscatter + mixByScatter(u_emission, vec3(0.0), wa, wb) * (1.0 - T);

5. 太陽光

太陽は平行光源で、向き \(l\)（光源へ向かう単位ベクトル、\(l_y > 0\)）、放射照度 \(\pi I\) とする（\(I\) はコードの u_lightColor。\(\pi\) を付けると、反射率 \(\rho_s\) の Lambert 面の反射輝度が \(\rho_s I\) になる）。 入射する放射輝度はデルタ関数 \(L_i(x, \omega) = \pi I\,\delta(\omega - l)\,T_l(x)\) で、\(T_l(x)\) はその点から太陽までのフォグの透過率である。 散乱項は

\[ L_s(x) = \pi\,\beta(\cos\theta)\,I\,T_l(x), \qquad \cos\theta := \mathrm{rd} \cdot l \]

となる。\(\theta\) は光の進む向き \(-l\) と、散乱してカメラへ向かう向き \(-\mathrm{rd}\) のなす角で、太陽を見るレイ（\(\mathrm{rd} = l\)）で \(\cos\theta = 1\)。 位相関数の部分 \(\pi\beta(\cos\theta)\) はレイ上で定数（\(\mathrm{rd}\) も \(l\) も変わらない）なので積分の外に出る。等方散乱 \(\beta = 1/4\pi\) なら \(1/4\) で、 コードの sunPhase は \(\pi\beta\) を返し、\(g = 0\) で 0.25 になる（7 節）。 太陽光が高さフォグに関わる経路は 3 つあり、Playground とスライドでは別々のトグルにしている。エネルギー保存を保つなら 3 つとも入れる。

5.1 太陽の減衰（sun attenuation）

サーフェスの点 \(p\) に届く太陽光は \(\pi I\,T_l(p)\) で、\(T_l\) は \(p\) から太陽の向き \(l\) に無限遠までの透過率、\(\tau_l\) はその光学的深さである。 3 節の式で \(c = p\)、\(\mathrm{rd} = l\)、\(d = \infty\) とすれば

\[ \begin{aligned} \tau_l(p) &= \frac{a\, e^{-f(p_y - h)}}{f\, l_y} = \frac{\tau_\uparrow(p)}{l_y} \\ \tau_\uparrow(p) &:= \frac{\kappa(p)}{f} \\ T_l(p) &= e^{-\tau_l(p)} \end{aligned} \]

である。\(\tau_\uparrow(p)\) は高さ \(p_y\) から真上に無限遠までの光学的深さで、コードの tauFromTop である。 sunTransmittance は heightFogOpticalDepth に \(d = 10^5\) を渡しているが、値は \(e^{-\tau_\uparrow(p)/l_y}\) と同じである。 距離フォグの光学的深さは無限遠まで \(\kappa_u t\) で増えるので \(T_l = 0\) になる。太陽が常に消えるのは意図しない結果なので、太陽の減衰には距離フォグを入れない。 

// 真上に無限遠までの高さフォグの光学的深さ tau(y) = kappa(y) / f
vec3 tauFromTop(float y) {
  return u_density * exp(-u_falloff * (y - u_baseHeight)) / u_falloff;
}

vec3 sunTransmittance(vec3 p) {
  if (!u_sunAttenuation) return vec3(1.0);
  vec3 tau = heightFogOpticalDepth(p, u_lightDir, 1e5, u_density, u_falloff, u_baseHeight);
  return exp(-min(tau, vec3(60.0)));
}

5.2 カメラへの内散乱（sun inscatter）

太陽光の内散乱は、ボリュームレンダリング方程式の散乱項に上の \(L_s\) を入れて

\[ \pi\beta(\cos\theta)\, I\, \rho \int_0^d T(c, x_t)\,\kappa(x_t)\,T_l(x_t)\,dt \]

である。\(T_l(x_t)\) が \(t\) に依存するので 4 節の \(\int T\kappa\,dt = 1 - T\) はそのまま使えないが、この積分は閉じる。 \(u(t) := \tau_\uparrow(x_t)\) と置くと、\(u(t) = u(0)\,e^{-f\,\mathrm{rd}_y t}\)、\(\kappa(x_t)\,dt = -du / \mathrm{rd}_y\)、 \(\tau(c, x_t) = (u(0) - u(t)) / \mathrm{rd}_y\) で、\(T_l = e^{s u}\)（\(s = -1/l_y\)）だから

\[ \begin{aligned} &\int_0^d T(c, x_t)\,\kappa(x_t)\,e^{s\,u(t)}\,dt \\ &= \frac{e^{s\,u(0)} - T(c, x_d)\,e^{s\,u(d)}}{1 + s\,\mathrm{rd}_y} \end{aligned} \]

となる。\(1 + s\,\mathrm{rd}_y = 0\)、つまり \(\mathrm{rd}_y = l_y\)（レイが太陽と同じ仰角で上がる方向）では被積分関数が \(\kappa\) の定数倍になり、極限は \(e^{s u(0)}\,\tau(c, x_d)\)。 \(s = 0\)（減衰なし）なら \(1 - T\) に戻る。 コードの modeIntegral がこれで、tauCam \(= u(0)\)、tauEnd \(= u(d)\)、tauView \(= \tau(c, x_d)\)、off \(= 0\) である。 太陽の減衰を入れないときは modeIntegral を呼ばず \(1 - T\) を直接使う。 

// レイに沿った積分 ∫_0^d T(t) kappa(t) e^{s tau(t) + off} dt の閉じた形 (tau は真上に無限遠までの光学的深さ tauFromTop)
vec3 modeIntegral(vec3 s, vec3 off, vec3 tauCam, vec3 tauEnd, vec3 tauView, float rdy) {
  vec3 atCam = exp(s * tauCam + off);
  vec3 atEnd = exp(-tauView + s * tauEnd + off);
  vec3 den = 1.0 + s * rdy;
  bvec3 sing = lessThan(abs(den), vec3(1e-2));
  return mix((atCam - atEnd) / mix(den, vec3(1.0), vec3(sing)), atCam * tauView, vec3(sing));
}

vec3 sunInscatter(vec3 c, vec3 rd, float d) {
  vec3 tauCam, tauEnd, tauView;
  rayTaus(c, rd, d, tauCam, tauEnd, tauView);
  vec3 hf, uf;
  fogMixFactors(c, rd, d, hf, uf);
  vec3 scatter = u_sunAttenuation
    ? modeIntegral(vec3(-1.0 / u_lightDir.y), vec3(0.0), tauCam, tauEnd, tauView, rd.y)
    : 1.0 - exp(-tauView);
  return u_lightColor * sunPhase(dot(rd, u_lightDir)) * u_albedo * scatter * hf;
}

\(T(c, x_t)\) に距離フォグが入ると \(e^{-\kappa_u t}\) が掛かって閉じなくなるので、4 節の \(A\) と同じ係数 \(1/(1 + \kappa_u t_h)\)（hf）を掛ける。 uf は \(B\) 側の係数で、ここでは使わない。距離フォグが 0 なら厳密である。 高さフォグが散乱した太陽光が距離フォグで薄まる分だけを見ていて、距離フォグ自身は太陽光を散乱しない（5.1 と同じ理由）。

5.3 サーフェスへの内散乱（sun inscatter ambient）

太陽光がフォグで散乱してサーフェスに届く分も単散乱（太陽 → フォグ → サーフェス）である。 正しくは、サーフェスの点 \(p\) から見た半球の全方向について 5.2 の積分を取り、法線との余弦で重みづけて足す。 これは閉じないので、空へ向かう代表方向 1 本 \(\hat\omega\)（6 節。コードの SKY_DIR）で \(d = \infty\) の内散乱を評価し、環境光に足す。 位相関数も、サーフェスから空へ向かう \(\hat\omega\) をレイの向きにして \(\cos\theta = \hat\omega \cdot l\) で評価する。代表方向 1 本というのがここの近似で、7 節の \(g\) が大きいほど誤差も大きい。 

vec3 sunInscatterAmbient(vec3 p) {
  return sunInscatter(p, SKY_DIR, 1e5);
}

6. サーフェスに届く環境光

サーフェスの点 \(p\) に半球の向き \(\omega\) から届く環境光は、空の光 \(L_a\) がフォグを通り抜ける分と、途中のフォグが散乱して届く分の和で、 その向きの透過率を \(T(\omega)\) とすれば \(L_a T(\omega) + \rho L_a (1 - T(\omega))\) である（4 節と同じ計算）。 これを余弦重みで半球平均すると

\[ \begin{aligned} &L_a\,\langle T \rangle + \rho\,L_a\,\bigl(1 - \langle T \rangle\bigr) \\ &= L_a\Bigl(1 - (1 - \rho)\bigl(1 - \langle T\rangle\bigr)\Bigr) \\ \langle T \rangle &:= \frac{1}{\pi}\int_{H^2} T(\omega)\,(n \cdot \omega)\,d\omega \end{aligned} \]

で、\(H^2\) は法線 \(n\) の側の半球である。\(\rho = 1\) なら \(L_a\) に戻る（吸収がなければフォグがあっても環境光は変わらない）。スライドと Playground ではこの 2 項を sky attenuation と sky inscatter ambient の 2 つのトグルに分けている。

\(\langle T \rangle\) は閉じない。上向きのサーフェスでは、5.1 の \(\tau_\uparrow(p)\) を使って \(\langle T \rangle = 2 E_3(\tau_\uparrow)\)、\(E_3(x) := \int_1^\infty e^{-xt}\,t^{-3}\,dt\) で、これは \(\exp(-1.5\,\tau_\uparrow)\) でよく近似できる （半球平均を斜め 1 方向の透過率で代表する係数 1.5 を diffusivity factor と呼ぶ）。 \(1.5 = 1 / (2/3)\) なので、これは \(y\) 成分（天頂角の余弦）が \(2/3\) の代表方向 \(\hat\omega\) 1 本の透過率と同じである。 サーフェスの向きは見ない（側面も同じ \(\hat\omega\) を使う）。側面の半球は下半分が地面までのフォグを通るので、正しくは \(\langle T \rangle\) がこれより小さい。 地面の高さをシェーダーに持ち込まないために、この 1 本で済ませている。距離フォグは \(d = \infty\) で \(T = 0\) になるので含めない（5.1 と同じ理由）。 

const vec3 SKY_DIR = vec3(0.0, 2.0 / 3.0, 0.745356); // 長さ 1、y = 2/3
vec3 skyTransmittance(vec3 p) {
  return exp(-min(tauFromTop(p.y) / SKY_DIR.y, vec3(60.0)));
}

vec3 shade(vec3 p, vec3 n) {
  float diff = max(dot(n, u_lightDir), 0.0);
  float sh = shadow(p + n * 0.02, u_lightDir);
  vec3 sun = u_lightColor * sunTransmittance(p);
  vec3 ambient = u_ambient;
  if (u_skyAttenuation || u_skyInscatterAmbient || u_emissionAmbient) {
    vec3 T = skyTransmittance(p);
    if (u_skyAttenuation) ambient = u_ambient * T;
    if (u_skyInscatterAmbient) ambient += u_ambient * u_albedo * (1.0 - T);
    if (u_emissionAmbient) ambient += u_emission * (1.0 - T);
  }
  if (u_sunInscatterAmbient) ambient += sunInscatterAmbient(p);
  return surfaceAlbedo(p) * (diff * sh * sun + ambient);
}

surfaceAlbedo はサーフェスの反射率、shadow は太陽へのレイマーチによるハードシャドウ（0 か 1）である。 発光するフォグに囲まれたサーフェスには全方向から発光が届くので、emission ambient では同じ代表方向の \(E(1 - T)\) を足す。

7. 位相関数

散乱する向きの偏りは Henyey–Greenstein の位相関数で表す。

\[ \beta_{HG}(\cos\theta) = \frac{1}{4\pi}\,\frac{1 - g^2}{\bigl(1 + g^2 - 2g\cos\theta\bigr)^{3/2}}, \quad \cos\theta = \mathrm{rd} \cdot l \]

\(g = 0\) で等方、\(g > 0\) で前方散乱（光の進む向きに散乱しやすい）、\(g < 0\) で後方散乱。 \(\cos\theta = 1\) は太陽を見るレイ（\(\mathrm{rd} = l\)）で、前方散乱ではここが最大になる。だから \(g > 0\) で太陽の周りのフォグが明るくなり、反対側が暗くなる。

5 節の通り、平行光源では \(\pi\beta(\cos\theta)\) がレイ上で定数なので、位相関数を入れても閉じた式はそのまま使える。 係数として 5.2、5.3、8 節の 3 つに同じ値をかける。環境光は全方向から同じ色なので \(\int \beta\, d\omega = 1\) となり、位相関数の形は関係しない。 

// 位相関数 × π。g = 0 なら 1/(4π) × π = 1/4 (等方)
float sunPhase(float cosTheta) {
  float g = u_phaseG;
  float g2 = g * g;
  return 0.25 * (1.0 - g2) / pow(max(1.0 + g2 - 2.0 * g * cosTheta, 1e-4), 1.5);
}

8. 光芒: 影つきの数値積分

柱が太陽光を遮ると、フォグの中に影の境界が光芒として見える。5.2 の被積分関数に、点 \(x_t\) から太陽が見えるかの可視性 \(V(x_t) \in \{0, 1\}\) を掛けたもの

\[ \pi\beta(\cos\theta)\, I\, \rho \int_0^d T(c, x_t)\,\kappa(x_t)\,T_l(x_t)\,V(x_t)\,dt \]

は閉じた式では書けないので、ここだけ数値積分する。レイを 48 単位まで 32 ステップの等間隔でレイマーチし、各点から太陽へ影のレイを飛ばして \(V\) を求める。 影のレイは柱だけを見るレイマーチ（fogShadow。SDF の値だけ進む sphere tracing を最大 24 ステップ、柱の上端まで）で、柱より上なら何もしない。 48 単位より先は影を無視して 5.2 の閉じた式に切り替え、手前の透過率をかけて足す。レイの透過率 \(T(c, x_t)\) が 0.005 を切ったら打ち切る。

等間隔のサンプルは隣のピクセルで同じ位置に落ちるので、影の境界が縞になる。開始位置をピクセルごとのハッシュ（hash21）でずらして縞をざらつきに変え、 さらにフレームごとに黄金比で回して、同じピクセルの誤差が毎フレーム別方向にぶれるようにしている（目の中で平均される）。 ざらつきの大きさはステップの長さで決まり、ステップ数を 2 倍にすれば半分弱になる。 

const int SHADOW_STEPS = 32;
const float SHADOW_RANGE = 48.0;
vec3 sunInscatterShadowed(vec3 c, vec3 rd, float d, vec2 pix, vec3 R) {
  float tEnd = min(d, SHADOW_RANGE);
  float dt = tEnd / float(SHADOW_STEPS);
  float jitter = fract(hash21(pix) + 0.618034 * u_frame);
  vec3 sum = vec3(0.0);
  for (int i = 0; i < SHADOW_STEPS; i++) {
    float t = (float(i) + jitter) * dt;
    vec3 p = c + rd * t;
    vec3 Tview = pow(fogTransmittance(c, rd, t), R);
    if (max(Tview.r, max(Tview.g, Tview.b)) < 0.005) break;
    float vis = fogShadow(p);
    if (vis <= 0.0) continue;
    vec3 kappaH = R * u_density * exp(-u_falloff * (p.y - u_baseHeight));
    sum += Tview * u_albedo * kappaH * sunTransmittance(p) * (vis * dt);
  }
  vec3 result = u_lightColor * sunPhase(dot(rd, u_lightDir)) * sum;
  if (d > tEnd) {
    vec3 pEnd = c + rd * tEnd;
    result += pow(fogTransmittance(c, rd, tEnd), R) * sunInscatter(pEnd, rd, d - tEnd);
  }
  return result;
}

サーフェスへの内散乱（5.3）は影を見ない。\(R\) は 9 節のノイズの平均で、ノイズなしなら 1 である。

9. ノイズ

フォグにムラをつけるために、消散係数にノイズ \(r : \mathbb{R}^3 \to [r_{\min}, r_{\max}]\) をかけて \(\tilde\kappa(p) = r(p)\,\kappa(p)\) とする。 光学的深さは

\[ \begin{aligned} \tilde\tau(c, x_d) &= \int_0^d r(x_t)\,\kappa(x_t)\,dt = \bar R\;\tau(c, x_d) \\ \bar R &:= \frac{\int_0^d r(x_t)\,\kappa(x_t)\,dt}{\int_0^d \kappa(x_t)\,dt} \end{aligned} \]

と書ける。これは \(\bar R\)（レイ上の \(r\) の \(\kappa\) 重み付き平均）の定義そのもので、厳密に成り立つ。 つまり閉じた式の \(\tau\) はそのまま使い、\(\bar R\) だけを見積もればよく、透過率は \(\tilde T = e^{-\bar R \tau} = T^{\bar R}\) になる。 スライドの「透過率を T の R 乗にする」はこれである。

\(\bar R\) はレイ上の数点でノイズを読み、重み \(\kappa(x_{t_k})\) の重み付き平均で見積もる（区間の幅は掛けない）。 サンプルの位置は \(t_0 = 1\)、\(t_k = 1 + 1.4^k\)（\(k \ge 1\)）の 10 本（約 22 単位まで）でカメラの近くに固める。 等間隔 \(t_k = dk/N\) にするとサンプル位置がサーフェスからの距離で決まり、模様がサーフェスと一緒に動いて見える。 重みに区間の幅を掛けないのも同じ理由で、掛けると遠い区間が重くなり床の近くのサンプルが支配する。 距離 \(d\) を超えた最初のサンプルは、区間のうち \(d\) までの割合で線形補間（mix）して入れ、\(d\) について連続にする。 

const int NOISE_SAMPLES = 10;
const float NOISE_STEP_EXP = 1.4;
vec3 noiseMean(vec3 c, vec3 rd, float d) {
  vec3 sum = vec3(0.0);
  vec3 wsum = vec3(0.0);
  float t = 1.0;
  float tPrev = 0.0;
  float step = NOISE_STEP_EXP;
  for (int k = 0; k < NOISE_SAMPLES; k++) {
    vec3 p = c + rd * t;
    vec3 w = u_density * exp(-u_falloff * (p.y - u_baseHeight)) + u_uniformDensity + vec3(1e-6);
    vec3 f = w * fogNoise(p);
    if (k > 0 && t > d) {
      float ratio = (d - tPrev) / (t - tPrev);
      return mix(sum / wsum, (sum + f) / (wsum + w), ratio);
    }
    sum += f;
    wsum += w;
    tPrev = t;
    t = 1.0 + step;
    step *= NOISE_STEP_EXP;
  }
  return sum / wsum;
}

// main
vec3 T = fogTransmittance(ro, rd, d);
vec3 R = u_noise ? noiseMean(ro, rd, d) : vec3(1.0);
T = pow(T, R);

ノイズ \(r\) は 3 オクターブの 3D バリューノイズ（振幅 0.5, 0.25, 0.125）を \([0, 1]\) に正規化し、\(\operatorname{mix}(r_{\min}, r_{\max}, \cdot)\) で範囲に写したもので、上向きに流す。 カメラは \(+z\) に進み続けるので、\(z\) の格子をワールドの周期 512 で巻き、座標の巻き戻しで模様が飛ばないようにしている。

\(\bar R\) を使うのはレイの透過率と、8 節の光芒の数値積分（消散係数に \(\bar R\) をかけ、レイの透過率を \(T^{\bar R}\) にする）である。 光芒がノイズを見ないと、サーフェスの透過率だけにムラがつき光芒にはつかないので、ノイズが体積ではなく画面上の模様に見える。 閉じた式の太陽の内散乱、太陽への透過率、サーフェスの環境光はノイズを見ない。これは意図した簡略化で、近似の一覧に載せる。 また \(\bar R\) はレイ 1 本につき 1 つの値なので、レイ方向のムラ（光芒の中の濃淡）は表現できない。

10. 近似の一覧

どこが厳密でどこが近似かをまとめる。「モデルの下で厳密」とは、単散乱・平行光源・一様な環境光というモデルを認めた上で積分に近似がないことを指す。

項目評価内容
高さフォグ・距離フォグの透過率厳密光学的深さの閉じた式（3 節）
環境光の内散乱 \(\rho L_a (1 - T)\)モデルの下で厳密\(L_s\) がレイ上で一定なので積分の外に出て、\(\int T\kappa\,dt = 1 - T\)（4 節）
発光 \(E(1 - T)\)モデルの下で厳密\(L_e = E\kappa\) と仮定（4 節）
高さフォグと距離フォグの混合近似\(I_h \approx A\)、\(I_u \approx B\)。最大誤差 0.06。片方だけなら厳密（4 節）
太陽の減衰 \(T_l\)モデルの下で厳密\(d = \infty\) の閉じた式。距離フォグは入れない（5.1）
太陽のカメラへの内散乱モデルの下で厳密\(\int T\kappa e^{s u}dt\) の閉じた式。距離フォグがあるときは混合と同じ近似（5.2）
太陽のサーフェスへの内散乱近似半球積分を代表方向 1 本で評価。影は見ない（5.3）
サーフェスの環境光 \(\langle T \rangle\)近似diffusivity factor \(e^{-1.5\tau_\uparrow}\)。サーフェスの向きを見ない。上向きのサーフェスではよく合う（6 節）
位相関数モデルの下で厳密平行光源なのでレイ上で定数（7 節）。5.3 では代表方向の近似に乗る
光芒数値積分32 ステップの等間隔レイマーチ + ずらし。48 単位より先は閉じた式（8 節）
