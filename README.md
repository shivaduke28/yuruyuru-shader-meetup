- 難しいことは説明しない（ボリュームレンダリング方程式など）
- シェーダーでレイマーチする人は通常の指数関数フォグは理解している
  - `color = lerp(fogColor, color, exp(- fog * distance))`
- これは以下の過程がある
  - ボリュームが均一
  - 内散乱に使う光が定数
  - 位相関数が定数（位相関数という単語を出す必要はない）
- 指数関数高さフォグ
  - `- a * exp(- f * (pos.y - h))`がフォグの強さ
